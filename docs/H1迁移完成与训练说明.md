# H1 迁移实现与本机训练说明

仓库：`/home/ljp/human_learn/SuperMimic-Reproduced-main`。更新日期：2026-11-05。

当前代码面向 **19 关节 Unitree H1**，使用 MuJoCo XML 描述机器人，通过 mjlab / MuJoCo Warp 进行训练仿真。世界模型、Actor/Critic、参考动作、评测和播放均使用同一 H1 骨架。这是现有仓库训练与仿真评测流程的迁移，不包含原仓库尚未实现的实机通讯、ONNX 导出或额外 MPC 控制器。

原迁移指南的第 2～17 章对应实现已接入；第 18 章的 G1/H1 动态切换属于后续设计，本次仍是 H1 专用版本。停用的 XML 定义和主要旧 G1 实现保留为注释。用户设置的 H1 默认关节角、PD 参数和动作缩放保留。

## 2. H1 维度和控制参数

| 数据 | 算式 | 维度 |
|---|---|---:|
| 动作/关节位置 | H1 实际可控关节数 | 19 |
| qpos | 根位置 3 + 四元数 4 + 关节 19 | 26 |
| qvel | 根线速度 3 + 根角速度 3 + 关节速度 19 | 25 |
| 状态 | qpos + qvel | 51 |
| 世界模型增量/状态误差 | 四元数的 4 维改用旋转向量 3 维 | 50 |
| 单帧本体观测 | 关节角 19 + 速度 19 + 根角速度 3 + 重力 3 + 上次动作 19 | 63 |
| 默认历史观测 | 10 × 63，按观测项组织历史 | 630 |
| 单帧目标特征 | 关节角 19 + 速度 19 + 重力 3 + 角速度 3 + 线速度 3 + 高度 1 | 48 |
| 默认目标输入 | 10 × 48；开启 anchor 额外加 9 | 480 / 489 |
| 仿真上下文 ξ | 脚摩擦 1 + 编码器偏置 19 + torso COM 偏移 3 | 23 |

控制关系仍是 `q_target = q_default + 0.25 * action`。仿真步长 0.005 s，decimation=4，策略和动作数据均为 50 Hz。PD 列表见 `robots/h1.py`；无需在训练 XML 内重新启用 motor 或 keyframe。

k=8 是世界模型监督的连续转移窗口，H=32 是想象策略优化长度。迁移到 19 关节没有自动缩短这两个时间长度。

## 3. 已准备的 H1 动作

本机 `data/npz/h1/` 当前有两段真实来源的 H1 参考动作，用于开始训练：

| 文件 | 帧数 | 帧率 |
|---|---:|---:|
| `default_pose_150frames.npz` | 249 | 50 Hz |
| `dance1_subject3_last.npz` | 1182 | 50 Hz |

来源目录：`/home/ljp/human_learn/whole_body/Beyondmimic_Deploy_H1_last/deploy_real/bydmimic/`。未修改来源文件。

原 NPZ 缺少关节名称。其配套 ONNX 的 `joint_names` 和来源仓库 `deploy_real/h1_config.py` 明确给出相同的训练关节顺序，与本仓库 XML 的深度优先顺序不同。因此转换过程：

1. 从配套 ONNX 读取 19 个来源关节名称，按当前 XML 名称重新索引关节角。
2. 使用来源的第 0 个 body 作为 pelvis；来源播放代码也使用该索引。不能把 ONNX 的 12 个 tracked body 名称直接当作 NPZ 全部 20 个 body 的顺序。
3. 使用米、Z 向上世界坐标和 wxyz 根四元数；重新采样并求速度。
4. 用当前 H1 XML 重算全部 20 个 body 的位置、朝向和速度。
5. 写入机器人、关节/body 名称、资产指纹、来源和帧率。

站立参考直接移入当前资产后，脚底悬空约 6.27 cm；已对整段根高度统一减去 `0.06168121896108694 m`，使脚底约离地 1 mm。没有逐帧贴地处理，避免破坏跳跃等动作。舞蹈保留原始高度；抽样脚底高度约为 -1.96 cm 至 0.49 cm，后续扩充数据时仍需审查重定向质量。

复现站立数据导入的命令：

```bash
cd /home/ljp/human_learn/SuperMimic-Reproduced-main
env -u PYTHONPATH -u PYTHONHOME .venv/bin/python scripts/data/import_h1_npz.py \
  --source /home/ljp/human_learn/whole_body/Beyondmimic_Deploy_H1_last/deploy_real/bydmimic/default_pose_150frames.npz \
  --onnx /home/ljp/human_learn/whole_body/Beyondmimic_Deploy_H1_last/deploy_real/bydmimic/2026-07-14_21-20-08_default_pose.onnx \
  --root-index 0 --root-height-offset -0.06168121896108694 \
  --out data/npz/h1/default_pose_150frames.npz --overwrite
```

舞蹈使用同目录 `dance1_subject3_last.npz` 和 `2026-07-14_14-47-04_dance_last.onnx`，`--root-index 0`，省略高度偏移。

其他来源必须自己明确其关节顺序和 pelvis 索引。没有 ONNX 时，可以用 `--joint-names-json names.json` 提供一个包含 19 个名称的 JSON 列表。**不能截取 G1 的 29 维动作作为 H1 动作。** G1 动作需要先做机器人运动重定向。

H1 CSV 无表头时为 26 列：根 xyz（米）、根四元数 xyzw、XML 顺序的 19 个关节角（弧度）。已有带 BONES 风格表头的 H1 CSV 可按列名重排，位置为厘米、Euler 角和关节角为度。

```bash
# 转换已经重定向到 H1 的 CSV；input-fps 按来源填写。
env -u PYTHONPATH -u PYTHONHOME .venv/bin/python scripts/data/csv_to_npz_batch.py \
  --input-dir data/raw/h1 --output-dir data/npz/h1 --input-fps 30 --workers 1

# 数据变多后可选择 compact 存储。
env -u PYTHONPATH -u PYTHONHOME .venv/bin/python scripts/data/build_library.py \
  --npz-dir data/npz/h1 --out data/library/h1_compact.pt --workers 1
```

`filter_bones_seed.py` 已能处理 H1，但名称筛选和可行性阈值仍是启发式规则，不代表已复现论文的 H1 数据筛选指标。当前两段数据没有经过该脚本批量剔除。

## 4. 训练、恢复、评测和播放

本机 `.venv` 已安装，不需要重新安装依赖。最直接的训练入口：

```bash
cd /home/ljp/human_learn/SuperMimic-Reproduced-main
bash scripts/train_h1.sh --run-name h1_train
```

该脚本默认使用 32 个环境、256 步经验容量、世界模型 batch=64（每轮 1 批）、策略 batch=32、k=8、H=32，保留原网络宽度，关闭 `torch.compile` 以降低首次运行成本。它是适合本机起步的配置；与论文的大批量训练预算不同。原始 `sm-train` 的 4096 环境默认值仍保留，不能把它当成本机已验证规模。

例如先只用站立动作训练 2000 个环境步：

```bash
bash scripts/train_h1.sh --run-name h1_stand \
  --data.clips default_pose_150frames --schedule.total-iterations 2000
```

TensorBoard 日志：`logs/<run-name>/tb/`。权重：`logs/<run-name>/ckpt_latest.pt`。恢复时需保持动作库、关节顺序和控制参数一致：

```bash
bash scripts/train_h1.sh --run-name h1_stand_resume \
  --data.clips default_pose_150frames \
  --resume logs/h1_stand/ckpt_latest.pt --schedule.total-iterations 10000
```

更换动作库后应开始新 run。Resume 会核对 clip 名称/长度/顺序，避免把旧的难度采样统计错配到新动作。旧 G1 checkpoint 或旧 packed library 会被明确拒绝，不自动裁剪网络参数。

```bash
# 两段动作的确定性评测。
env -u PYTHONPATH -u PYTHONHOME .venv/bin/python scripts/eval_benchmark.py \
  --ckpt logs/h1_train/ckpt_latest.pt --num-envs 2

# 本机窗口播放；无桌面时可以改为 --viewer viser。
env -u PYTHONPATH -u PYTHONHOME .venv/bin/python scripts/play.py \
  --ckpt logs/h1_train/ckpt_latest.pt --clips default_pose_150frames --viewer native

# 记录和渲染 H1 与参考动作。
env -u PYTHONPATH -u PYTHONHOME .venv/bin/python scripts/media/record_rollout.py \
  --ckpt logs/h1_train/ckpt_latest.pt --clips default_pose_150frames --out media/h1_rollout.npz
MUJOCO_GL=egl env -u PYTHONPATH -u PYTHONHOME .venv/bin/python scripts/media/render_rollout.py \
  media/h1_rollout.npz media/h1_video --seconds 5
```

`--policy.history`、`--env.future-frames` 和 `--env.anchor-obs` 会同步到训练环境与网络。评测、播放和录制从 checkpoint 恢复相同历史长度，避免加载权重后观测维度不匹配。
