## 安装和使用命令

本机已经安装完成。进入仓库后可检查环境，无须重新下载：

```bash
cd /home/ljp/human_learn/SuperMimic-Reproduced-main
env -u PYTHONPATH -u PYTHONHOME uv sync --locked --group dev --offline --check
```

将来需要安装缺失依赖或重建环境时，可执行：

```bash
env -u PYTHONPATH -u PYTHONHOME UV_CONCURRENT_DOWNLOADS=1 UV_HTTP_TIMEOUT=180 uv sync --locked --group dev
```

并发数和网络超时只影响下载，不改变锁定版本，见 [uv 官方环境变量说明](https://docs.astral.sh/uv/reference/environment/)。本次安装遇到官方包源下载缓慢，部分包从清华和阿里云镜像补齐，均与 `uv.lock` 的 SHA-256 完全一致；随后完成离线锁定同步。没有修改项目依赖、锁定文件或全局软件源。

通过 uv 使用仓库环境：

```bash
env -u PYTHONPATH -u PYTHONHOME uv run --no-sync python --version
env -u PYTHONPATH -u PYTHONHOME uv run --no-sync sm-train --help
```

也可以在终端中激活环境：

```bash
source /home/ljp/human_learn/SuperMimic-Reproduced-main/.venv/bin/activate
env -u PYTHONPATH -u PYTHONHOME python --version
env -u PYTHONPATH -u PYTHONHOME sm-train --help
```

命令中的 `env -u` 只清除本次进程的外部 Python 路径，避免 ROS 或其他项目的包进入当前环境，不修改用户的全局配置。

## 当前训练入口与训练规模

当前训练入口使用 19 关节 H1，正式训练数据已整理到 `data/npz/h1/`（站立和舞蹈两段）。推荐从本机启动脚本开始：

```bash
cd /home/ljp/human_learn/SuperMimic-Reproduced-main
bash scripts/train_h1.sh --run-name h1_train
```

该脚本使用 32 个环境、64 条世界模型样本、32 条想象轨迹，保留 k=8、H=32 和原网络宽度，关闭编译。末尾可追加训练参数覆盖默认值；例如 `--schedule.total-iterations 2000`。原始 `sm-train` 默认 4096 环境不属于本机已经验证的规模。
